# Cosmic Home title fonts

Lilita One provides the Homeward Glow title lettering. Fredoka supplies the
opening screen's subtitle and start prompt. Both are bundled locally with their
SIL Open Font License files.

Sources:
- https://github.com/google/fonts/tree/main/ofl/lilitaone
- https://github.com/google/fonts/tree/main/ofl/fredoka
